# Kustomisasi Cepat

- Kontak dan harga: edit `lib/site-config.ts`.
- Logo: gunakan `public/logo.png` sebagai aset logo utama.
- Warna: edit CSS variables di `app/globals.css`.
- Testimoni: edit array di `components/sections/testimonials.tsx`, lalu hapus label placeholder setelah menggunakan testimoni asli.
- Domain: ganti `nalara.example` pada `app/layout.tsx` dan `public/robots.txt`.
